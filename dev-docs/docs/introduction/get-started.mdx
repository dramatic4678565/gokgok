## Try now

Go to [excalidraw.com](https://excalidraw.com) to start sketching.

## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup and introduction.
- [@mosaic/mosaic](/docs/@mosaic/mosaic/installation) — docs for the npm package to help you integrate Mosaic into your own app.
- Editor — IN PROGRESS. Docs describing the internals of the Mosaic editor to help in contributing to the codebase.
- [@excalidraw/mermaid-to-excalidraw](/docs/@excalidraw/mermaid-to-excalidraw/installation) - Docs for the mermaid to mosaic parser
