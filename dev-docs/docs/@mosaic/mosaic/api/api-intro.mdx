# API

Currently the **API** is divided into 3 broad categories 👇

- [Props](/docs/@mosaic/mosaic/api/props) - The `props` you can pass to the `Mosaic` component.
- [Children components](/docs/@mosaic/mosaic/api/children-components) - Official components you can use to customize the UI.
- [Utils](/docs/@mosaic/mosaic/api/utils) - Utilities and helpers you can use to export, restore and more.
